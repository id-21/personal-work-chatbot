<critical_notes>
## CRITICAL NOTES
- **Do not edit files in this directory** — They are managed by the shadcn CLI. Run `npx shadcn@latest add <component>` to add new ones.
- **Import from `@/components/ui/<name>`** — e.g., `import { Button } from "@/components/ui/button"`.
- **All components accept a `className` prop** — Use Tailwind to customize appearance rather than modifying the component source.
</critical_notes>
